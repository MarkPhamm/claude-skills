**How to apply:** Every chat reply. If a yes/no fits, lead with it. Overrides the length of [[explain-jargon-and-acronyms]] (still gloss terms, but in a few words).

**TL;DR first, plain mechanics:** 2026-10-20 repeat ("why tf don't you say it like that, why so wordy... answer it in tldr, i don't like to read"). No abstract phrasing ("earliest version open-ended"), no caveat essays. Caveats: max 1-2 short bullets.

**Conversational tone:** 2026-10-27, the user said "i want thinks in tldr fashion, more conversational, less wordy, that's how i take notes, and i want you to answer in that way too". Write like a quick chat with a teammate, not a report. See [[user-learning-style]].
