When editing the user's notes or question lists, keep the structure they already chose and only add to it or reorder inside it. Order items from the smallest grain up: transactions (offer list, reservation, entitlement) first, then member, account, host, then lookups.

**Why:** In the Salesforce questions session (2026-10-26), I regrouped the questions by entity. The user rejected that and asked to keep the original "what is it / how do they link" sections and only reorder the questions.

**How to apply:** Keep the user's headings and short "What's X / How does X link to Y" style. Do not restructure unless asked. Related: [[be-concise]], [[explain-jargon-and-acronyms]].
